ESP32 升级说明

这里更新的是 ESP32 探针及其管理网页，不会烧录外接 STM32。

  1. 先结束 STM32 调试会话，选择适配本设备的 .amphipkg 正式包。
  2. USB 升级：用数据线连接电脑；Wi-Fi 升级：电脑和探针需在同一局域网，默认管理密码为 12345678。
  3. 校验通过后点击升级，保持供电和连接，等待设备重启并显示“升级完成”。

日常升级保留已保存的 Wi-Fi 配置。旧固件首次安装 rlyoulink 需先通过 USB 基础安装工具迁移；设备无法启动时，使用 USB 下载模式救援。未显示完成时，请查看操作日志确认结果。
