# 第三方组件

Python 3.13：见 PYTHON-LICENSE.txt。Python 包的版本清单与许可见 python-packages.json、python-packages/；pyserial 许可单列。冻结运行库随包分发，PyInstaller 使用其 bootloader 分发例外。

OpenOCD：GPL-2.0-or-later。对应源码 openocd-1bf1ac444.tar.gz、jimtcl-f160866.tar.gz、cmsis-dap-tcp-fix.patch 及构建脚本随包提供；许可正文位于 openocd-licenses。esptool 4.11.0 的源码另附 esptool-4.11.0-source.tar.gz，许可见 python-packages/esptool。

libusb 1.0.28：LGPL-2.1-or-later，许可见 libusb，对应源代码见 libusb-1.0.28.tar.gz。hidapi 0.15.0 许可见 hidapi，可按其 BSD 许可使用。DLL 独立存放在 tools/openocd/bin，可替换兼容版本以重新链接；修改版本的兼容性由使用者验证。

本目录的源代码和许可属于发布材料，不是历史过程日志。表情包来源与署名说明见项目 README。
